Third Person LAN Multiplayer Project (UE 5.4.4)

📌 Описание проекта

Данный проект представляет собой базовый прототип игры от третьего лица, разработанный на Unreal Engine 5.4.4.

Проект выполнен в рамках тестового задания компании «ЛАЗЕРТАГ» и демонстрирует реализацию базовых мультиплеерных механик с использованием локальной сети (LAN).

⸻

🎮 Реализованный функционал
 • 🌀 Система кувырка (Dodge Roll)
 • Активируется на клавишу Q
 • Полностью синхронизирована по сети (server-authoritative)
 • Корректно работает в мультиплеере
 • 💬 Мультиплеерный чат
 • Обмен сообщениями между игроками
 • Работает в рамках одного сервера
 • 🌐 LAN-мультиплеер
 • Создание и подключение к серверу через IP-адрес
 • Работа исключительно в локальной сети

⸻

🛠 Используемые технологии
 • Unreal Engine 5.4.4
 • Blueprints (основная логика)
 • Клиент-серверная архитектура (LAN)

⸻

📥 Установка

1. Перейдите в раздел Releases и скачайте архив с игрой или проектом Unreal Engine.
2. Распакуйте архив в любую папку

⸻

🚀 Как запустить
 1. Запустить .exe файл (Build)
 2. Один игрок создает сервер
 3. Остальные подключаются по IP-адресу хоста
 4. Использовать:
 • Q — кувырок
 • Чат — для общения между игроками
